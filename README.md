# GemBlast

GemBlast is a cross-platform Match-3 puzzle game built with TypeScript and React Native (Expo / Expo Web).

## Features & Architecture
- **8x8 Grid**: Classic match-3 puzzle grid.
- **5 Gem Types**: Ruby, Sapphire, Emerald, Topaz, Amethyst.
- **Pure TypeScript Engine**: Core mechanics isolated under `src/engine/` with unit test coverage.
- **Cross-Platform**: Mobile and web ready via Expo.

## Getting Started

### Installation
```bash
npm install
```

### Running Tests
```bash
npm test
```

### Type Checking
```bash
npm run typecheck
```

### Running the App
```bash
npm start
```
